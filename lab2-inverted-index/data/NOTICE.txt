Python tutorial source documents

The ten files downloaded into documents/ are English reStructuredText (RST)
source documents from the official Python 3.14 tutorial. The original RST
markup and code examples are retained. Consequently, the experiment's
English-word tokenization also includes words occurring in markup and code;
these files have not been converted to plain prose articles.
