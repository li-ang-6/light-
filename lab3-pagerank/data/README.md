# PageRank 实验图

`graph.tsv` 是本实验自行构造的六节点有向图，使用 UTF-8 编码。每行第一个字段为节点名，后续字段为该节点指向的节点，字段用制表符分隔。只有节点名的一行表示没有出边。

图包含普通有向链接、明确列出的无出边节点 `E`，以及只出现在链接目标中的节点 `F`。读取时将所有源节点与目标节点合并，目标节点即使没有独立输入行也参与排名。重复边先去重。

两种实现使用相同输入，初始排名为 `1/N`，阻尼系数为 `0.85`，恰好迭代 10 轮。每轮将无出边节点的排名总和均分给所有节点：

`PR_next(v) = (1 - 0.85) / N + 0.85 * (来自入邻居的贡献之和 + 悬挂节点排名总和 / N)`

每套程序保留 `state-00` 到 `state-10` 的状态，最终文件按 `(节点,PR值)` 输出。独立 Python 核验器从原图重新计算并核对全部节点及每轮结果，另比较两套程序最终结果与排名和。

这是教学用的小图，便于检查边界情况和观察迭代结果；运行耗时主要受作业启动与集群配置影响，不宜据此推断大规模图上的性能。
